# 场景与内容规划

先用材料与受众确定表达目的，记录 task_profile.scenario、objective、delivery_context（live/standalone/mixed）。scenario 可为 report、business、teaching、product、research、personal 或 general，也可填更具体的任务名。它用于选择指导，不强制固定页序。

| 场景 | 组织重点 | 按需核对 |
|---|---|---|
| 工作汇报 | 结果、进度、问题、下一步；管理者需要决策时先给结论 | 时间范围、指标口径、责任与计划 |
| 商业方案 | 对方需求、方案、价值、执行与具体诉求 | 金额、计算口径、前提与可验证承诺 |
| 教学培训 | 学习目标、解释、例子、操作与练习 | 概念准确性、前置知识、步骤顺序 |
| 产品品牌 | 受众需求、功能、使用场景与差异 | 实际产品能力、品牌规范、素材真实性 |
| 科研答辩 | 研究问题、方法、结果、解释 | 来源、样本量、单位、统计与结论强度；读 scientific-design.md |
| 个人展示 | 经历、作品、本人贡献、匹配度 | 任职时间、成果归属、作品和数据 |

现场演讲页帮助听众跟上，不照抄演讲稿；独立阅读页补足必要上下文，可使用更详细的图注、表格和段落。密度随用途选择，不能给所有任务套同一字数。

每页写清主旨、支持材料、必要可见文字与布局意图。没有支持材料时缩小判断范围或记录缺失，不用口号填空。封面、目录、总结、展望、行动页、问答和致谢按实际用途决定，不作为固定套餐。客户方案可以以明确请求结束，教学可以以练习结束，数据汇报可以以结论结束。

用户要求先看样张、选择风格或复刻时 interaction=review。直接完成或未要求逐步确认时 autonomous。自动模式选择风格和检查样页都是内部工作，不能记录为用户批准。必要问题集中提出，其余根据已知任务继续。
