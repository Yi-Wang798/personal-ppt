# 长期默认设置

以下是长期偏好与默认设置。当次请求优先；字体与字号策略已按用户要求设定。

| 项目 | 默认 |
|---|---|
| 语言 | 简体中文，保留必要英文术语 |
| 画布 | 16:9，1280×720 CSS px；字号明确用 pt |
| 模式 | per-slide：每页先内置生图、显示完整设计图，再按图原生制作；仅明确要求少量样张时切换 representative |
| 图片显示 | 每页设计图在聊天中可见，附页码；不以提示词或文件路径代替图片，不等最终 PPT 才展示 |
| 交互 | 先展示母版候选并等待作者选择；母版确认后生成分页；最复杂样页的实际重建对照需先验收，之后批量重建，无需每页重复确认 |
| 页数 | 未指定时按内容选择，通常 8–12，总数包含封面 |
| 密度 | speaking：每页一个重点；阅读报告切换 reading |
| 材料用途 | 上传的 PPT/PDF 默认只提取内容和证据；只有明确要求沿用风格时才复制设计 |
| 字体 | 中文使用微软雅黑（Microsoft YaHei），英文使用 Times New Roman；同一段落混排时按文字分别设置字体，实际验证字体可用性 |
| 字号 | 母版阶段按生成图和排版自主确定各角色字号，不预设固定范围；选定母版后同角色全套统一，不逐页任意改大小 |
| 视觉 | 复用用户确认的母版壳与内容布局，固定元素/标题位置/文字层级统一；只按内容需要使用同体系布局，不强迫每页换版 |
| 配色 | 优先从 NPG（Nature 风格参考）、AAAS（Science 风格参考）或 NEJM 色板选择；明确背景、文字、重点与数据分组角色，详见 scientific-design.md |
| 生图 | 内置工具，不要求 API 密钥，不固定未经验证的模型名 |
| 交付 | PPTX + 逐页预览 + 项目源；PDF/演讲稿按请求 |
| 输出 | 用户目录优先，否则工作区 output/<主题名>；版本用新名字 |
| 长期风格 | `~/.personal-ppt/styles/<风格名>/`，用户要求保存时写入 |

减少内容前核对必需信息；不得为一页一重点擅自增加明确页数或删关键结果。先精炼非关键文案、调整构图，再考虑字号；仍放不下说明冲突。

起始方向（是可选设计路线，不与题材绑定为固定答案）：

- NPG 证据编辑：中性浅底、蓝/珊瑚红重点对比；原图放大、关键结果贴近证据，机制页可用不同图文关系。
- AAAS 结构表达：深蓝、紫色或蓝绿分工，强调色有明确意义；左右对照、多面板结果、路径解释和局部深色章节可以搭配。
- NEJM 对比叙述：蓝、暖橙和红色作为分类参考，适合清晰的组间对照、趋势和方法差异；不默认将所有颜色同时铺满页面。

不要每次科研任务都选择白底蓝绿同一种方向。根据材料和受众选择，配色与版式分别决策。期刊参考色板不是官方 PPT 模板；不复制期刊 logo 或暗示期刊背书。用户指定字体和自主字号判断保持不变。

默认边距约画布宽 5%，间距围绕 16/24/32px 统一选择。配色随主题调整，外部项目的风格禁令不直接继承。


v1.6：生成图是设计参考，可主动纠正其排版缺陷。真实原图/数据/机制比例、可读性与页面均衡优先；尽量保留风格与主要布局，局部优化记录原因无需每页确认。居中相对所属容器分别设置对象与文字的水平/垂直对齐；整段加粗覆盖中英文全部 runs。


v1.7：科学内容定稿后再生图；制作待办默认不上屏。短说明优先完整一行，长说明按语义换行；图标+标题整体定位，同级卡片等宽等距，不默认所有正文居中。参考图颜色使用实际区域取样；科研证据原配色保留，内容、排版、颜色分别验收。
