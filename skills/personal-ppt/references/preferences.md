# 个人默认设置

当次明确要求优先。以下偏好沿用旧版，不因通用化修改字体或字号策略。

| 项目 | 默认 |
|---|---|
| 语言 | 简体中文，按任务保留必要英文；用户指定语言时按要求 |
| 画布 | 16:9，1280×720 CSS px，字号使用 pt |
| 制作 | per-slide：每页内置生图并展示完整设计图，再按图重建可编辑 PPT；不增加制作路线选择 |
| 交互 | autonomous 自动完成；用户要求先看样张或选择风格时 review |
| 页数 | 按内容、时长和用途决定；用户指定总页数时遵守 |
| 密度 | 现场演讲用 speaking；独立阅读用 reading |
| 材料用途 | 上传 PPT/PDF 默认提取内容和证据；明确要求时才继承外观 |
| 字体 | 中文微软雅黑 Microsoft YaHei；英文 Times New Roman；混排按文字分别设置 |
| 字号 | 母版阶段按内容与排版自主判断；同角色全套统一，不设通用固定字号 |
| 配色 | 按主题、受众和品牌选择，建立背景、文字、重点、分类的颜色角色；期刊配色为可选 |
| 图片 | 原图完整等比放入；复杂元素作为独立可替换素材 |
| 交付 | PPTX、逐页预览、项目源；PDF、演讲稿按请求 |
| 位置 | 用户指定目录优先，否则 output/<主题名>；新版本用新文件名 |
| 长期风格 | 用户要求保存时写入 ~/.personal-ppt/styles/<风格名>/；升级不覆盖 |

边距和间距由母版统一。素材比例不同或设计图有排版缺陷时，保持风格和主要关系，主动调整布局与留白并记录原因。居中分别检查对象、文字和组件整体；整段加粗覆盖全部中英文 runs。

不为一页一重点擅自改用户页数；先精炼非关键文案、调整构图，再判断字号。仍有真实冲突时说明具体情况。
